Research contribution · ECC 2023

A Hierarchical Approach for Strategic Motion Planning in Autonomous Racing

The policy chooses strategy through reference parameters, while the motion planner retains the vehicle model and constraints. HILEPP-I outputs desired speed and lateral position. HILEPP-II additionally sets the speed and lateral cost weights. Both interfaces are implemented; the included trained checkpoint uses HILEPP-I.

Implemented in this recreation

  • Actual SAC: a squashed Gaussian actor, twin critics, target critics, and entropy regularization.
  • 4,000 training interactions, one training seed, 64-step episodes; NumPy-only checkpoint inference.
  • Paper-style observations and progress/rank reward, with a −10 failure penalty added for this recreation.

Differences from the paper

  • CasADi/IPOPT replaces the original acados/HPIPM solver in these runs.
  • Opponents use lane tracking and car following; the ego predicts constant opponent speed and lateral position.
  • Obstacle ellipses are expressed in Frenet coordinates with bounded slack (0–0.08). Collision checks approximate bodies in Frenet coordinates.
  • No recursive-feasibility terminal set or safety guarantee. Synthetic circuit sections and short episodes replace the paper’s larger benchmark.

Held-out car evaluation

One training seed · three tasks · five test seeds per task

The recreated SAC policy achieved a mean held-out return of 171.7, compared with 162.2 for the fixed-reference planner (+5.9%). These are small-scale results from this implementation, not the paper’s reported benchmark.

Each method uses the same five held-out seeds (10000–10004) for each of three tasks: 45 episodes in total. The fixed planner requests 30 m/s at track center; the policy can request 18–32 m/s and ±4.5 m. The replay always shows seed 10000. Dots show individual test episodes; bars show means. Validation uses three separate seeds (8000–8002). The best validation checkpoint was selected before test evaluation.

Run the research

Use the included new checkpoint, retrain SAC, or connect your own normalized policy to the planner.

# Put the improved vehicle_gym checkout beside this repository
python3 -m venv .venv
source .venv/bin/activate
pip install -e ../vehicle_gym -e '.[train,dev]'
python -m hilepp.evaluate --checkpoint-dir checkpoints
python -m hilepp.train --steps 4000 --seed 7 --output checkpoints/new-run
python -m http.server 8000 --directory docs
Numerical setup and provenance

Python 3.9 · NumPy 1.26.4 · SciPy 1.13.1 · CasADi 3.8.1 / IPOPT · PyTorch 2.8.0 on CPU. The planner uses 12 intervals of 0.25 s, a five-state Frenet model, RK4 integration, and three opponents. Simulation uses five substeps per interval. Full settings, checkpoint provenance, and limitations are documented in the repository.

What is included in the repositories?

Python source, regression tests, recorded evaluations, editable web visualization, a scientific figure generator, citation metadata, and GitHub Pages deployment. The HILEPP wrapper depends on the improved vehicle_gym package instead of duplicating its dynamics or planner.
